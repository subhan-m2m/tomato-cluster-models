6 · Move toward the AgriTwin workflow

Now make the counts useful by row.

We have a repeatable counting baseline, saved results, and examples of common mistakes. The next goal is a reviewable photo-to-row demonstration.

  1. Agree what a group means

    Set simple rules for hidden fruit, edge groups, and unclear stems. Check whether the project needs verified trusses.

  2. Check new greenhouse photos

    Review missed and extra boxes, fix unclear labels, and measure errors on scenes the model has not seen.

  3. Connect counts + ripeness

    Save each result with its photo, greenhouse row, and capture date so the dashboard can show the right row.

  4. Let a supervisor review it

    Show the row map, photo evidence, and picking priority together. Confirm whether the result helps plan a shift.

Team takeaway: we can now turn photos into visible counts. Completing the labels improved the group model. Next, we test new scenes and connect the results to AgriTwin’s row view.

Repeated photos can show the same tomatoes. Whole-row totals need a way to avoid counting them twice; harvest-weight forecasting also needs real harvest data.
