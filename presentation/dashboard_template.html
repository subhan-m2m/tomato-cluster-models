What this told us

The pretrained checkpoint needed greenhouse-specific adaptation. It missed every labeled fruit with the Tomato class.

An all-fruit diagnostic counted other classes such as Apple, but aligned with almost none of the tomato boxes. It was not accepted as a tomato-counting result.

Conclusion: the unadapted checkpoint did not meet the counting requirement.

07 / Agree on the next experiment

Improve the labels, then test model changes.

  1. Agree on the counting rule

    Define singleton groups, hidden fruit, image-edge groups, and unclear stems. Confirm whether the target is visual clusters or verified trusses.

  2. Review and version the labels

    Resolve missing fruit and inconsistent group boundaries with a second annotator. Keep the original export and publish corrected labels as a new version.

  3. Separate scenes across splits

    Keep nearby frames and the same plants together. Reserve a fresh final set, including confirmed empty scenes. Viewed test images become development material.

  4. Run controlled comparisons

    Repeat the 480-pixel baseline first. Then try 640-pixel input and other changes one at a time on the same validation set.

  5. Freeze settings and test once

    Choose checkpoint and confidence on validation. Evaluate the fresh final set with count error, precision/recall, and reviewed failures.

  6. Share a reproducible handoff

    Record dataset version, model hash, split, threshold, results, and examples. Agree on an acceptable error target before declaring the baseline complete.

Decision for the team: agree on the cluster definition, assign label review, and choose the scene-separated final set. No agreed accuracy acceptance target is recorded yet.
